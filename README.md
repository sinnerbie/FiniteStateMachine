# FiniteStateMachine

Completar esta tarea ha resultado ser bastante sencillo. Las únicas dificultades fueron la implementación de _Animator.SetTrigger_ que no siempre logra cambiar de un estado de animación a otra, y el cálculo del ángulo entre el jugador y el NPC para la funcionalidad de los booleanos _CanSeePlayer_ y _IsPlayerBehind_ ya que se me olvido referenciar la dirección del jugador según la posición del NPC en vez de solo la posición del jugador.
